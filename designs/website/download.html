Installs for you only. No administrator password needed.

On Windows, run the installer. If Windows says it protected your PC, click More info, then Run anyway.

Command line

The artifice command comes with the app.

The program inside Artifice answers every command, for scripts, servers and agents that run shell commands. Give it a short name once, then open a new terminal.

# add this line to ~/.zshrc
alias artifice="/Applications/Artifice.app/Contents/MacOS/artifice-desktop"
# add this line to your profile (notepad $PROFILE)
Set-Alias artifice "$env:LOCALAPPDATA\Artifice\artifice-desktop.exe"

Installed Artifice somewhere else? Use that folder instead. Then check it works:

$ artifice --version
