Every file

Your AI can use files it can't open.

Most AI tools can't read Word, Excel, PowerPoint or Visio files on their own. Artifice reads them, and scanned PDFs on a Mac, so your AI can answer from the documents your company actually keeps.

Always the version you just savedArtifice reads a change about 0.7 seconds after you save, and checks for changes again before every briefing.

No upkeepAdd a folder once. Only the parts that changed are read again, so a big project stays quick.

Tidying up loses nothingA file that moved keeps its links, what Artifice learned about it, and the memories that point to it.

Your files are never changedArtifice only reads. Each document is read in its own process; macros never run and links are never followed.

AI tools

One setup for every AI tool you use.

Connect each tool once, in one click, and it works in every project you add. Nothing is written into your project, and there's nothing to paste into a prompt.

  1. It finds your AI tools. AI tools in Artifice lists the ones on this computer, each with Connect.
  2. It backs up, then adds one entry. The tool's settings file is copied to Artifice's backups folder first. For Claude Code, Connect also adds the hooks.
  3. It tells you what's next, like “Start a new Claude Code session to use it.”
  4. It follows where your AI works. In a project you've added, your AI gets briefings. In any other folder, it gets nothing.

Disconnect removes only Artifice's entries. If you set Artifice up yourself, with claude mcp add or by hand, it still shows as connected.

For developers

Developers can script every part of it.

Everything the app does is a command, any MCP app can connect, and Claude Code gets hooks so it is briefed even when it never calls a tool.

Runs over stdio, with twelve tools. Claude Code gets five of them and two sentences of instructions, and none is always loaded, because tool definitions ride along on every turn.

Command line · artifice

Add folders, connect tools, ask, remember, run playbooks and see savings. artifice doctor prints a report with no file contents or questions in it, safe to paste into a bug report.

The commands you'll use most

The same engine runs the app, the CLI and the MCP server, so anything you do in one shows in the others.

Read the docs 
# add a folder, once
$ artifice init ~/code/acme

# connect your AI tool, once for all projects
$ artifice connect claude-code

# what's connected, and how
$ artifice connect
# print the briefing your AI would get
$ artifice ask "where do we round invoice totals?"

# ranked one-line pointers to passages
$ artifice search "rounding"

# savings across all your projects
$ artifice savings
# save a decision, with where it came from
$ artifice remember "Ledger amounts are stored in cents" --kind decision --source src/ledger.rs

# every note, and what needs a look
$ artifice notes

# write Memory out as Markdown
$ artifice export
# add a playbook from a Markdown file
$ artifice job add budget-review.md

# run it, filling in the blank
$ artifice job run budget-review --input month=November

# every playbook, with its steps and runs
$ artifice job list
# prints a server definition for any MCP app
$ artifice connect generic
