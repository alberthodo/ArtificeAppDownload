How codes work

The small print, in plain words.

A code turns on the same Artifice as Pro, for a set time. Here's what to expect.

What it looks like

ARTF- and eight letters and digits, in two groups of four. There's no 0, O, 1, I or L, so it's easy to read out and type.

How long it lasts

Each code gives a set number of months, or free time with no end. It starts the day you redeem it, and Account › Plan shows until when. A few codes give a discount on Pro instead; the app says which.

One per person

You can use a code once on your account. A code for a class or an event works once for each person, until its places run out. Codes also have a last day to redeem them.

Time adds up

If free time from another code is still running, the new code's time is added on to the end of it.

Already paying for Pro?

Then the code isn't needed for now. Email support@tryartifice.com with it, and we'll turn it into credit on your plan.

When it ends

Artifice stops briefing your AI tools, and your projects, memories and playbooks stay readable. Choose Pro in Account › Plan to carry on. More about plans.

Code not working? Check it against the one you were given, or ask whoever gave it to you. Still stuck? Write to support@tryartifice.com with the code.
