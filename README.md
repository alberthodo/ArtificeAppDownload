# Download Artifice

Artifice is the librarian for your folders. It catalogs your documents, notes and code, keeps them fresh, and hands your AI tools only the context they need.

**[Download the latest version](https://github.com/alberthodo/ArtificeAppDownload/releases/latest)**

| Computer | File |
|---|---|
| Mac with Apple Silicon (M1 and later) | `Artifice_<version>_aarch64.dmg` |
| Mac with Intel | `Artifice_<version>_x64.dmg` |
| Windows PC (most) | `Artifice_<version>_x64-setup.exe` |
| Windows on ARM (Snapdragon) | `Artifice_<version>_arm64-setup.exe` |

Once installed, Artifice updates itself. See what changed in each version in the [changelog](CHANGELOG.md).

This repository only hosts installers and the update feed (`latest.json`). The app's source code is private.
