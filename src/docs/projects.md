# Projects

A project is any folder you add to Artifice: a code repository, a shared drive folder, or a folder of documents. You can add as many as you like.

## Adding a project

Click the project name at the top of the sidebar, then **Add a project…**, and pick a folder. Artifice reads it in the background, and Home shows the progress. You can keep working meanwhile.

Artifice warns you before reading a very large folder or your whole home folder. It never reads system folders or the whole disk.

## What Artifice reads

Artifice reads documents (PDF, Word, Excel, PowerPoint, OpenDocument, RTF, EPUB, CSV, emails), notes, text and code. It keeps up with your changes on its own while the app is open.

It always skips:
- secrets, such as files that hold passwords or keys;
- dependency and build folders;
- files your project's `.gitignore` leaves out.

To skip more, open **Settings › This project › Skipped files** and pick folders, or add patterns. **Library** lists the files Artifice doesn't read, and why.

## Switching projects

The project menu shows your five most recent projects. With more than five, type in **Find a project…** or open **All projects**.

## Moved or renamed folders

If a project's folder moves, its status becomes **Can't find the folder**. Click **Locate…** and pick its new place.

## Removing a project

Open **Settings › This project › Remove project…**. Your files stay where they are. You can also delete Artifice's data for the project.
